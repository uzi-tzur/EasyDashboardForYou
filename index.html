Export to Google Sheets

One-time setup: Google requires every app to have its own OAuth Client ID. It's free, takes about 5 minutes, and isn't a secret.

  1. Open the Google Cloud Console and create a project.
  2. Enable the Google Sheets API.
  3. Set up the OAuth consent screen (External). Add yourself as a test user, or publish the app.
  4. Under Clients, create a client of type Web application. Add this page's address as an Authorized JavaScript origin:
  5. Paste the Client ID below.

You'll be asked to sign in with Google. The app can only access spreadsheets it creates. It can't see the rest of your Drive.
